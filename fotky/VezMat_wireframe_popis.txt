VĚŽMAT – TEXTOVÝ POPIS WIREFRAMU A LOGIKY PŘECHODŮ

==================================================== OBRAZOVKA 1 –
Přihlášení / Úvod ====================================================
Popis: Úvodní obrazovka aplikace. Obsahuje název hry „VěžMat“ a možnosti
vstupu do systému.

Prvky: - Tlačítko: Přihlášení - Tlačítko: Vstoupit - Možný návrat nebo
ukončení

Logika přechodů: - Přihlášení → Hlavní menu - Vstoupit → Hlavní menu

==================================================== OBRAZOVKA 2 –
Hlavní menu ==================================================== Popis:
Centrální rozcestník hry.

Prvky: - Hrát - Statistiky - Nastavení - Možný návrat zpět

Logika přechodů: - Hrát → Výběr věže / patra - Statistiky → Obrazovka
Statistiky - Nastavení → Obrazovka Nastavení

==================================================== OBRAZOVKA 3 – Výběr
věže / patra ==================================================== Popis:
Hráč si vybírá konkrétní věž nebo úroveň.

Prvky: - Seznam věží / tematických okruhů - Náhled obtížnosti - Tlačítko
pokračovat

Logika přechodů: - Pokračovat → Úvodní dialog (čaroděj) - Zpět → Hlavní
menu

==================================================== OBRAZOVKA 4 –
Úvodní dialog ====================================================
Popis: Čaroděj vysvětluje princip hry, soubojů a postup věží.

Prvky: - Textová bublina (obecný popis souboje) - Tlačítko pokračovat

Logika přechodů: - Pokračovat → HRA

==================================================== OBRAZOVKA 5 –
Nastavení ==================================================== Popis:
Možnost upravit parametry hry.

Prvky: - Zvuk - Obtížnost - Jazyk - Zpět

Logika přechodů: - Zpět → Hlavní menu

==================================================== OBRAZOVKA 6 –
Statistiky ==================================================== Popis:
Přehled výkonů hráče.

Prvky: - Tabulka úspěšnosti - Počet poražených nepřátel - Dokončená
patra - Zpět

Logika přechodů: - Zpět → Hlavní menu

==================================================== OBRAZOVKA 7 – HRA
(Hlavní herní uzel) ====================================================
Popis: Centrální herní stav. Zde probíhá samotné hraní. Tato obrazovka
je uzlem, ze kterého se větví různé herní situace.

Možné stavy:

1)  Prázdná místnost
    -   Čaroděj krátce komentuje situaci.
    -   Možnost pokračovat dál.
    -   Přechod zpět do HRA (další místnost).
2)  Truhla
    -   Hráč nalezne odměnu.
    -   Získání předmětu / bonusu.
    -   Návrat do HRA.
3)  Souboj
    -   Nepřítel pokládá matematický příklad.
    -   Hráč vybírá odpověď.
    -   Správná odpověď → Nepřítel ztrácí život.
    -   Špatná odpověď → Hráč ztrácí život.
    -   Po poražení nepřítele → návrat do HRA.
4)  Miniboss (konec patra)
    -   Silnější nepřítel.
    -   Více kol příkladů.
    -   Po poražení → postup do dalšího patra.
    -   Po prohře → konec hry / restart.
5)  Boss (konec věže)
    -   Finální protivník.
    -   Série náročnějších úloh.
    -   Výhra → dokončení věže.
    -   Prohra → možnost opakovat věž.

Logika přechodů: HRA funguje jako cyklus: HRA → (Prázdná místnost /
Truhla / Souboj) → HRA Na konci patra: HRA → Miniboss → HRA (další
patro) Na konci věže: HRA → Boss → Dokončení / Návrat do menu

==================================================== OBRAZOVKA 8 – Konec
hry ==================================================== Popis: Shrnutí
výsledku (výhra nebo prohra).

Prvky: - Text výsledku - Tlačítko opakovat - Tlačítko návrat do menu

Logika přechodů: - Opakovat → HRA / začátek věže - Menu → Hlavní menu

==================================================== CELKOVÁ LOGIKA
SYSTÉMU ====================================================

Přihlášení → Hlavní menu → Výběr věže → Úvodní dialog → HRA

HRA tvoří hlavní herní smyčku: - generuje náhodné místnosti (boj,
truhla, prázdná místnost), - po určitém počtu místností následuje
miniboss, - po dokončení všech pater následuje boss, - po vítězství je
věž dokončena.

Vedlejší větve: - Nastavení (vrací se zpět do menu) - Statistiky (vrací
se zpět do menu)

Celý systém je postaven jako uzlový diagram s centrálním herním cyklem.
